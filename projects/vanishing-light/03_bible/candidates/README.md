# E-06 visual anchor candidates

These five RGB PNG files were generated as original, fictional LUMEN concept art. They are
candidate assets, not an approval record.

## Candidate set

- `E06_character_bible_v1.png` — four-panel continuity sheet.
- `E06_front_v1.png` — anchor B: front medium close-up.
- `anchor_A_lighthouse_back_v1.png` — anchor A: reusable rear-view composition.
- `E06_hands_v1.png` — HANDS: human right hand / metal left forearm.
- `E06_evolved_eyes_v1.png` — EVOLVED_EYES: both optical eyes.

All files are 1672×941, opaque RGB, 16:9, and within the documented DashScope image input
limits. Their visual identity and left/right asymmetry were checked manually after generation.

## Human gate

The filmmaker must inspect the images and explicitly approve or replace them before any paid
batch video generation. Approval is recorded by changing the corresponding `anchors[].approved`
value in `film.yaml` from `false` to `true` in a dedicated commit. Approval must never be inferred
from the mere presence of a file.
