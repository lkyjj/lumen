# Submission checklist

## Repository and security

- [ ] All previously exposed GitHub/ModelScope/DashScope credentials revoked.
- [ ] Fresh credentials exist only in local or platform-managed secrets.
- [ ] Full tests and secret scan pass.
- [ ] Public GitHub repository includes source, tests, `.qoder/`, README and no private media/key.
- [ ] Default branch tracks `origin/main`.

## Human creative gates

- [ ] E-06 identity and four anchor candidates explicitly approved.
- [ ] D9 decision recorded as GO or Plan B.
- [ ] A human has watched the complete master without prior story context.
- [ ] No real-person likeness or existing film/game IP is present.

## Film

- [ ] 14 final clips and all attempts retained outside Git.
- [ ] At least three shots have before → critique → corrected-after evidence.
- [ ] Master is H.264, at least 1280×720 and exactly 100 seconds.
- [ ] End card contains originality statement and model/tool list.
- [ ] Bilibili/public video link opens without authentication.
- [ ] Original master uploaded to the competition form.

## Film Agent

- [ ] ModelScope Studio public URL opens on the free CPU tier.
- [ ] Demo tab performs zero API calls and loads without credentials.
- [ ] BYOK tab shows dynamic worst-case price and requires confirmation.
- [ ] BYOK key isolation has been tested with two concurrent sessions.
- [ ] Creation note B links to repository and Studio.

## Articles and form

- [ ] Film creation note published on ModelScope Learn.
- [ ] Agent workflow creation note published on ModelScope Learn.
- [ ] Registration status confirmed before the official registration deadline.
- [ ] Final form submitted with buffer rather than at the deadline.

External links and current deadlines must be verified on the live competition site immediately before
submission; the planning document is not treated as a permanent source of truth.
