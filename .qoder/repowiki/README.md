# LUMEN Repo Wiki

> 状态：人工编写、仓库内版本化、供代码审查使用。

本目录记录 LUMEN 的目标架构和审查基线。它是依据仓库中的 `PLAN.md` 与 `HANDOVER.md` 整理的项目文档，**不是 Qoder `/knowledge` 自动生成的 Repo Wiki，也不冒充自动扫描、自动同步或已验证实现的结果**。

当前仓库仍处于文档与规则搭建阶段。本文描述的是待实现架构；只有代码、测试和实际运行证据存在后，相关能力才能标记为“已实现”或“已验证”。

## 文档入口

- [architecture.md](architecture.md)：目标组件、数据流、边界、关键不变量与当前实现状态。
- `../rules/`：项目、电影语言和 Provider 契约规则。
- `../agents/`：四个项目级专家 Agent 的职责约束。

## 维护约定

1. 架构变化必须与代码和数据契约同一提交更新。
2. 文档区分“计划”“已实现”“已验证”，不得将设计意图写成运行事实。
3. 若未来实际运行 Qoder `/knowledge`，应明确标注生成时间、输入提交和人工修改；不要覆盖本目录的来源声明。
4. 凭据、认证头、真实外部响应载荷和完整 Base64 媒体不得写入 Repo Wiki。
